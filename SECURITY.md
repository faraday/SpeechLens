# Security Policy

## Supported versions

Security fixes are provided for the latest released version of SpeechLens.

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Use this repository's private **Report a vulnerability** form in the Security
tab.

Include the affected:
- SpeechLens version
- macOS version and hardware,
- reproduction steps or a proof of concept
- the expected and actual behavior

Include relevant logs only after removing user audio, personal file paths, and
other sensitive information.
