# SpeechLens Listening Demo Manifest

These MP3 files are browser-friendly listening copies for the public README.
Each before/after pair was encoded with identical settings. Encoding retained
the source rate and duration; the MP3 files are not quality-test oracles.

## Reproduction outline

1. Build the packaged release CLI with `Tools/package-local.sh --configuration release`.
2. Enhance each lossless input with the pinned weights and
   `--chunk-seconds 5.0`.
3. Encode source and enhanced WAV files with the packaged helper, using
   `-map_metadata -1 -c:a libmp3lame -b:a 192k` and the pair's native rate.
4. Run `Tools/verify-publication.sh` to validate rates, durations, checksums,
   notices, links, and release-document contracts.
